## 🛠️ Multi-Cloud & Tech Stack Architecture

- **Web Frontend:** Next.js 15 (App Router), React 18, Vanilla CSS Design System, Framer Motion
- **Mobile Engineering:** Flutter, Dart, Android & iOS Native
- **Cloud & Realtime DB:** Firebase & Cloud Firestore, Firebase Authentication, Firebase Admin SDK
- **Cloud Infrastructure & Storage:** Amazon Web Services (AWS) compute pipelines, S3 storage buckets
- **Edge CDN & Security:** Cloudflare global edge network, SSL/TLS encryption, DNS & DDoS protection
- **Backend & APIs:** Node.js, Express, RESTful APIs, Secure Webhook Integrations
